# Code of Conduct

This project follows a simple rule: be practical, respectful, and useful.

Contributors are expected to:

- discuss ideas and tradeoffs in good faith;
- avoid personal attacks;
- keep examples free of private seller data;
- help make the project understandable for operators as well as developers.

Maintainers may remove comments, issues, or pull requests that are abusive, spammy, or expose private data.

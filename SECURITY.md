# Security

This project should never contain private marketplace credentials, seller reports, spreadsheet IDs, service account files, customer data, or real financial reports.

If you discover sensitive data in this repository, please open a private security advisory if available or contact the maintainer directly through GitHub.

## Data Handling Rules

- Use anonymized sample data.
- Do not commit `.env` files.
- Do not commit service account JSON files.
- Do not commit marketplace API tokens.
- Do not commit real customer, price, margin, or sales reports.

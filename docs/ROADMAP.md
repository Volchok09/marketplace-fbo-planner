# Roadmap

## 0.1 Public Extraction

- Generic planning data model.
- JSON rules and weekly run input.
- CLI plan generation.
- Sample data.
- Documentation for the original spreadsheet-plus-AI workflow.

## 0.2 Spreadsheet Workflow

- Google Sheets template.
- Safe sheet allowlist for upload.
- Technical plan-data tab.
- Manual edit validation.
- Export-friendly summary tables.

## 0.3 Marketplace Importers

- Wildberries CSV/XLSX importer.
- Ozon CSV/XLSX importer.
- Shared normalization tests.
- Warehouse and cluster mapping files.

## 0.4 Global Marketplace Adapters

- Amazon FBA restock report adapter.
- eBay fulfillment planning adapter.
- AliExpress / cross-border marketplace adapter.
- Configurable region and route packs.

## 0.5 AI Maintenance Layer

- Prompt templates for weekly planning review.
- Rule change extraction from operator feedback.
- Pull request review checklist for adapter changes.
- Regression tests for stockout and box-capacity scenarios.

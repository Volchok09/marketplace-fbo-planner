# Product Vision

Marketplace FBO Planner aims to become a lightweight operations layer for sellers who are too complex for manual spreadsheet planning but not ready for an expensive ERP or marketplace operations platform.

## Target User

The first target user is an independent marketplace seller or small manufacturer who:

- sells across multiple marketplaces;
- ships to multiple fulfillment warehouses or clusters;
- has production or purchasing constraints;
- still uses spreadsheets as the daily operating surface;
- needs transparent replenishment decisions instead of black-box automation.

## North Star

Turn weekly replenishment from a fragile spreadsheet exercise into an auditable workflow:

1. Import marketplace signals.
2. Normalize demand and stock.
3. Apply route, production, reserve, and box rules.
4. Generate a draft shipment plan.
5. Let a human review and edit it.
6. Preserve corrections as future rules.

## What This Is Not

- Not a complete ERP.
- Not a seller dashboard.
- Not a black-box auto-shipment bot.
- Not a replacement for human operational judgment.

## Long-Term Direction

- More marketplace adapters.
- More product-category rule packs.
- Spreadsheet and API outputs.
- AI-assisted plan review.
- Community-contributed anonymized fixtures.
- Better simulation of stockout risk and logistics cost tradeoffs.
